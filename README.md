# Android Mirror Manager

Official Windows installer releases of **Android Mirror Manager**, a Windows app for mirroring and controlling Android devices over USB.

## Download

Open the [latest release](https://github.com/EduFilesPH/android-mirror-manager-releases/releases/latest) and download:

**Android Mirror Manager Setup** — the file ending in `_x64-setup.exe`

The installer includes the runtime components required for Android mirroring. Installed copies check this page for signed updates and ask before installing them.

Windows may show an "Unknown Publisher" or SmartScreen notice because the installer is not yet Authenticode code-signed.

## About this repository

This repository contains only official compiled releases: installers, updater signatures and the updater `latest.json` file. The source code is maintained separately.
